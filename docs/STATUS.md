# 当前验证状态

- 本机验证：60 项固件逻辑测试和 54 项网页测试通过。
- PlatformIO 在 nodemcuv2、sim_tx 和 sim_rx 三个环境均生成固件。
- PC 层覆盖人数轨迹、固定计时、时段、成员确认与否决、断网、UART 和云端模拟。
- 飞鸢已具备设备端适配契约、Mock、上下行字段和诊断脚本。实际 SDK、设备认证、物模型 ID、成员身份及可信时间来源待板上核实。
- HC-SR04 的测距处理与 KY-032 的采集已落入代码。实际微秒测量回调必须在对应板型上验证后提供，默认配置拒绝启动外设。
- 本机枚举到的串口均为蓝牙串口。EG800Z 和两块 ESP8266 尚未刷写和实测，需在隔离台架验证实物接收。
- 真实 OFF 保持禁用。PWA 去留为 `PENDING_DECISION`。
- 公开仓库只保存项目代码和示例，实物凭据应留在设备配置。
