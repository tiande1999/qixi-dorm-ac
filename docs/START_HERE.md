# 新同伴从这里开始

你只要先弄明白三件事：项目最终想做什么、现在能运行什么、你接下来负责哪一步。

## 1. 先体验网页

按 [首页](../README.md) 的命令打开网页，完成新手引导。进入演示控制台，依次试“最后一人离开”“提前确认关机”“通行歧义”。这样能看到人数、等待、取消和关机之间的关系。

目前这些操作都是模拟。右上角铃铛里的系统通知调用了浏览器能力，但消息仍来自模拟场景，网页也没有连接真实设备。

## 2. 再看实物连接

[架构说明](ARCHITECTURE.md) 解释模块怎样配合，[硬件说明](../hardware/README.md) 解释安装在哪里。EG800Z 负责决定，ESP8266 负责执行红外；手机不是现场自动关机的必要条件。

现在不需要先学完全部编程和电子课程。按下面顺序做小实验：

| 模块 | 最少需要学的内容 | 动手路径 | 主要代码 |
|---|---|---|---|
| 开发板基础 | 供电与信号电平、GPIO、日志 | 确认型号 → 最小脚本 → 电压与引脚记录 | `firmware/eg800z/board_config.py` |
| 门口采集 | 上拉、触发/释放、消抖 | 单独挡 A/B → 开关门 → 记录通行轨迹 | `inputs.py`、`main.py` |
| 人数统计 | 状态机、异常、人工校准 | 电脑回放 → 单人实测 → 逐次对账 | `counter.py`、`controller.py` |
| 红外收发 | 载波、完整状态帧、独立 OFF | 原遥控器采集 → 两次比较 → 多种状态试关机 | `firmware/esp8266/` |
| 两板通信 | UART、校验、短期执行许可 | 电平核对 → 双向通信 → 计时与取消 | `link.py`、`protocol.py` |
| 网页展示 | HTML/CSS、JS 模块、状态驱动 UI | 运行网页 → 改一处页面 → 观察状态与日志 | `web/dist/` |

## 3. 按四周计划分工

先读 [同伴版计划](planning/宿舍空调项目-给同伴的四周计划.md)，需要详细任务编号时看 [完整计划书](planning/宿舍空调项目-四周实施计划书-v4.0.md)。

H 主要提供实物、测量和安装；S 主要运行工具、保存日志和记录测试；AI 先做资料核对、设计、代码和错误分析。每到一个阶段，再通知 AI 开始对应任务。

```text
在做哪一步：

执行了什么操作：

完整日志或测量值：
这次与上次改了什么：
```
