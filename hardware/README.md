# 硬件：准备什么，装在哪里

这里是首版安装方案，尺寸都是试装起点。最终需要拿到实物型号、门口尺寸和测量记录后定稿。

先读 [接线关系](wiring.md)，把 [引脚记录表](pin-map.md) 填完整。实际 GPIO、电平与器件引脚没有核对前，不按常见线色直接连接。

## 安装位置

| 部件 | 首次试装位置 | 要验证什么 |
|---|---|---|
| 红外 A / B | 门锁侧固定支架，离地约 0.9～1.1 m；沿通行方向间隔约 20 cm | 深浅衣服、靠两侧和中间都能检测；开关门不会伪装通行 |
| 门磁 | 门框上部靠门锁侧，另一半在对应门板 | 关门吸合、开门释放，线材不受拉扯 |
| 两块主板、屏幕、按键 | 门内墙面同一控制盒，约 1.3～1.5 m 高 | 方便校准、看屏幕，门板碰不到 |
| 红外学习接收头 | 控制盒正面 | 原遥控器能够稳定采集 |
| 发射头 | 靠近空调原接收窗，先试 5～15 cm | 不遮挡原遥控器，用最终线长可靠响应 |

A 靠走廊，B 靠室内；现场验证进入时的实际先后。不要上下排列，不要装在会移动的门板上。漫反射传感器不是对射光束，标称距离不等于所有衣物下的有效覆盖。

## 人和 AI 怎么配合

AI 负责器件资料、原理、电阻计算、接线图、驱动程序、日志分析。人负责提供实物信息，测量电压，接线焊接，走过门口，操作原遥控器并观察空调。

四周原型只做低压控制器，靠无线红外与空调连接；关机指遥控器关机后的待机，不修改空调 220V 线路。
