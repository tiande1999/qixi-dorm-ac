# 接线与安装

先核对并测量各模块实际电平。HC-SR04 常见版本使用 5V，Echo 应按实测电平适配到 EG800Z，禁止把 5V Echo 直接接入低压 GPIO。核对 Trig 的高电平输入门限。KY-032 的输出极性和电平按实物测量，门磁用干接点和适配电压的上拉。所有非隔离低压信号共地。

沿通行方向划分两个检测区域，初始 HC-SR04 靠走廊，KY-032 靠室内。记录空门口、有人遮挡、门板打开和多条通行路径的距离与触发时间；门板进入检测区时先调整位置。超声双阈值、测量周期、KY 消抖和通行超时从 `board_config.py` 标定。

`echo_reader(trigger, echo, timeout_us)` 必须返回测得的回波高电平微秒值或 `None`。核实板上脉宽捕获 API 或用逻辑分析仪验证微秒计时分辨率与最坏等待时长；模拟时用回放数据。`inputs.make_echo_reader` 提供可注入的轮询候选实现。只有在实物确认微秒时钟、回绕差值函数和触发脉宽后，才将对应函数注入该实现。

EG 与 ESP A 串口短线连接，双方 TX/RX 各自做电平适配。发射 LED 用限流电阻及低压 MOSFET 驱动。暂停开关同时切断发射供电并向 EG 输入暂停。ESP B 的接收头按所购型号电源和引脚约定接线。

模拟测试把发射和接收置于有遮光的独立盒或用遮光管直连光路，并远离真实空调，检查接缝遮挡。接收板使用自身 LED 与串口显示验证结果，ESP A 与 ESP B 之间不接状态线。完整台架试验包括未知红外、重复 OFF、遮挡、断线和重启。
