# 连接关系与上板前核对

这份说明给出功能连接。EG800Z 的具体针脚尚未确认，先填写 [引脚记录表](pin-map.md)，再形成最终逐线接线图。

| 来源 | 目标 | 说明 |
|---|---|---|
| 传感器 A / B 输出 | EG 两路 GPIO | 按实际输出类型适配；确认是 NPN 下拉后才能采用对应光耦输入方案 |
| 门磁干接点 | EG GPIO 与 GND | 上拉到已确认的输入电平 |
| 加、减、确认按键 | EG 三路 GPIO | 本地校准和学习，软件消抖 |
| 暂停开关状态触点 | EG `arm` GPIO | 配合另一组触点断开发射供电；软件收到后取消待关流程 |
| EG TX / RX | ESP RX / TX | 核对电压，必要时转换；短距离 9600、8N1 |
| 红外接收头输出 | ESP GPIO13 | 选择支持 3.3V 的器件，核对实际引脚顺序 |
| ESP GPIO14 | MOSFET 驱动 | 不能把远置发射管直接当 GPIO 负载 |
| OLED SDA / SCL | ESP GPIO4 / GPIO5 | 核对屏幕供电、地址与上拉 |
| ESP 软件串口 RX / TX | GPIO12 / GPIO16 | 板载 USB 串口留给下载与调试 |

GPIO 编号不等于某些开发板标注的 D 编号；以实际开发板对照表为准。GPIO 供电电压和整板 USB 供电电压也不是同一回事。

## 发射驱动初值

```text
5V → 发射暂停开关 → 100Ω限流 → 红外LED → MOSFET漏极
                                            源极 → GND
ESP GPIO14 → 100Ω → MOSFET栅极
                         └─ 100kΩ → GND
```

原方案为 TSAL6200 类 940 nm 发射管与支持 3.3V 栅极驱动的 MOSFET（如 AO3400A）。100Ω 是近距离试发的初值，需要结合实际器件和测量复核；不要取消限流来增加距离。

暂停开关需要能同时表达软件暂停并切断发射电源的接法。实际开关触点和安装方向由实物核对，不能只在网页点“暂停”代替物理输入。

## 验证顺序

1. 分别确认两块板型号、供电和输入容许电压。
2. 单独接一路输入，读取稳定高低电平，再接其他传感器。
3. 验证门磁和暂停输入，记录实际有效电平。
4. 验证两板串口收发，再接计时与执行握手。
5. 检查发射电流和极性，用真实空调验证独立 OFF。
6. 固定后以最终线长重测，留下型号、接线、版本与结果。
