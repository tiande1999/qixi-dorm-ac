# 栖息 · 宿舍空调助手

一个可操作的宿舍空调交互演示网站，支持电脑和手机。当前使用模拟数据，没有接入真实硬件。

在线体验：[打开栖息](https://qixi-dorm-ac-demo.beamygala1.chatgpt.site)

## 第一次打开

先完成三步引导：

1. 选择 **4 人寝或 6 人寝**，床位示意和成员列表同步变化。房型不会改写实际在寝人数。
2. 体验红外遥控教程，模拟按下原遥控器的 OFF，了解收码、验证与安装过程。
3. 设置空房等待时间，支持 **1～60 分钟**，默认 15 分钟，也可以直接选择 5、10、15、30 分钟。

房型、等待时间和引导完成状态保存在当前浏览器。右上角“房间与自动设置”可随时修改或重看引导。刷新后演示恢复为初始的 3 人在寝，保留上述偏好设置。浏览器禁止本地存储时，设置仅在本次打开期间生效，页面会提示。

## 关机提醒如何工作

人数可信、人数为零、门关稳定且设备就绪后，开始预设倒计时，并显示页面内最高优先级提醒。

| 选择 | 结果 |
|---|---|
| 立即确认关机 | 不必等倒计时结束，复核条件后提前执行一次 |
| 继续等待，到点自动关机 | 收起提醒，倒计时继续 |
| 不操作 | 倒计时照常进行，到点自动执行 |
| 按 Escape 收起提醒 | 等同于继续等待，不会取消自动关机 |
| 暂停本次关机 | 明确取消并暂停；手动恢复后重新计时 |

每轮空房只自动提醒一次，收起后可从流程卡片再次打开。有人进入、开门、人数异常或关键设备失联会取消待执行流程。确认和倒计时到点相遇时只生成一次执行。

## 快速演示

1. 完成初次引导，点击“进入一人 / 离开一人”查看人数变化。
2. 在“演示控制台”选择“最后一人离开”，体验完整的自定义倒计时。
3. 选择“提前确认关机”，在剩余 1 分钟时点击确认；也可不操作，观察到点自动执行。
4. 选择“即将自动关机”，约 14 秒看完请求、接受、发送与模拟结果。
5. 到“空调与学习”完成六步模拟学习，然后校准人数。
6. 到“设备管理”尝试断线、重启；到“事件记录”筛选、搜索、导出记录。

控制台可设置 1× / 15× / 60×、暂停模拟时钟或推进 1 / 15 分钟。快捷场景会刻意设置较短的剩余时间，便于展示；普通空房流程使用保存的等待时间。

## 手机桌面与通知

点击右上角铃铛或首页“把栖息放到手机桌面 → 去设置”。页面包含 iPhone、Android 和电脑教程，以及通知状态检测、主动授权、发送测试和故障排查。

应用清单、桌面图标、独立窗口和演示缓存已补齐。系统通知由仍在运行的网页发起；锁屏 / 关闭页面后的远程宿舍提醒尚未接入。测试成功只证明当前设备接受了通知显示请求。

实现说明、官方资料和后续路径见 [手机桌面与提醒方案](../docs/web/手机桌面与提醒方案.md)。

## 本地运行

安装 Python 后，在此文件夹运行，或双击 `启动本地演示.cmd`：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

浏览器打开 `http://127.0.0.1:4173`。按 Ctrl+C 停止服务。需要通过 HTTP 打开，不要直接双击 `dist/index.html`。

## 演示范围

- 浏览器端没有后端、登录、真实设备或外部运行时依赖。
- “已发送”和“模拟关机完成”分别呈现；后者来自软件模拟观察器。
- 原有 EG800Z / ESP8266 固件未修改，自定义等待时间目前只作用于网页演示。
- 当前人数和日志不跨刷新保存，也不跨设备同步；需要留存可导出 JSON。
- 页面内提醒继续无需权限；右上角铃铛提供桌面安装、可选系统通知授权与测试。关闭网页后的远程推送尚未接入。
